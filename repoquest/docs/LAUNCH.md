## GitHub release notes: v0.1.0

**RepoQuest 0.1.0: first public release**

Understand any codebase. Find your way in. Make your first contribution.

Features:
- Import any public GitHub repository by URL, with rate-limit handling and large-repo support
- File explorer: search, syntax-highlighted preview, entry points, uses/used-by navigation
- Interactive architecture map. Confirmed relationships (from import statements) are drawn separately from inferred ones (folder names)
- Source-cited repository summary and execution flow, with no AI required
- Optional AI explanations (Claude or local Ollama) grounded in fetched files only
- First-contribution assistant that reads issue content, not just labels
- Shareable guide pages with social preview images

Known limitations: see README → "Known limitations".
